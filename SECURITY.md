# Security policy

Report suspected vulnerabilities privately to **support@vallkey.com** with the subject “Security report”. Include the affected component and version, reproduction steps, expected behavior, and impact. Use synthetic credentials and remove account data from attachments.

Do not publish working credentials, customer data, or exploit details in a public issue. If a credential has been exposed, revoke it at its issuer; deleting a commit does not revoke the credential.

Security fixes are made on the default branch and included in subsequent releases. Older releases do not have a separate backport commitment. No response-time guarantee or paid bounty is implied by this policy.
