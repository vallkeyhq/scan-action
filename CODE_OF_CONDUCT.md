# Code of conduct

Treat contributors and users respectfully. Critique ideas and code without personal attacks. Harassment, discriminatory language, threats, doxxing, and deliberate disclosure of private information are unacceptable.

Keep issues and pull requests relevant, constructive, and reproducible. Respect maintainers’ decisions about scope and technical direction.

Report conduct concerns privately to support@vallkey.com. Maintainers may edit or remove content, close discussions, or restrict participation when needed to protect the community. Maintainers are subject to the same standards.
